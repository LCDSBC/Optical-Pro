# OptiCalc Pro

Aplicativo Flutter profissional para Optometria e Ótica.

## Dashboard Principal

O módulo inicial entrega uma experiência dark mode premium com:

- cards modernos para módulos clínicos;
- atalhos rápidos para rotinas frequentes;
- menu lateral responsivo;
- animações suaves de entrada e interação;
- visual em azul escuro inspirado em Apple/Tesla.

## Módulos

- Pacientes
- Refração
- Lente de Contato
- Prismas
- Multifocal
- Histórico
- Configurações

## Validação

- `dart format .`
