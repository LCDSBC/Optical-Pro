# OptiCalc Pro

Aplicativo Flutter profissional para Optometria e Ótica, com Material Design 3,
Provider e arquitetura modular por funcionalidade.

## Módulo Refração

O módulo inicial inclui:

- tela **Nova Receita**;
- campos ESF, CIL, EIXO e ADD para OD/OE;
- transposição automática;
- equivalente esférico;
- interpretação clínica;
- dark mode premium em azul escuro.
