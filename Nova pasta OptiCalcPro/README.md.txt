# OptiCalc Pro

Sistema profissional para Optometria e Ótica desenvolvido em Flutter.

---

# Visão Geral

O OptiCalc Pro é uma plataforma moderna criada para automatizar cálculos ópticos, interpretação de receitas, conversão de lentes e gerenciamento clínico.

O aplicativo será utilizado por:

* optometristas,
* óticas,
* clínicas,
* estudantes de optometria.

O objetivo principal é criar o sistema óptico mais completo e moderno do mercado brasileiro.

---

# Objetivos do Sistema

* Automatizar cálculos ópticos
* Interpretar receitas automaticamente
* Converter óculos para lentes de contato
* Auxiliar montagem óptica
* Gerenciar pacientes
* Integrar IA futuramente
* Integrar OCR para leitura de receitas
