# Formulas Opticas - OptiCalc Pro

## Refracao

### Equivalente Esferico

```text
EE = ESF + (CIL / 2)
```

### Transposicao

```text
Novo ESF = ESF + CIL
Novo CIL = -CIL
Novo EIXO = eixo +/- 90 graus
```

## Prismas

### Regra de Prentice

```text
P = c x F
```

Onde:

- `P` = prisma
- `c` = descentracao em centimetros
- `F` = potencia da lente

## Lente de Contato

### Conversao por Vertice

```text
FLC = F / (1 - dF)
```

Onde:

- `F` = potencia da lente
- `d` = distancia vertice em metros

## Distancia de Trabalho

```text
D = 1 / distancia
```

## Multifocal

### Adicao

ADD calculada baseada em:

- idade
- acomodacao residual
- distancia de trabalho

## Terapia Visual

### AC/A

```text
AC/A = convergencia acomodativa / acomodacao
```

### NRA/PRA

Baseado em estimulacao acomodativa positiva e negativa.

### Flexibilidade Acomodativa

```text
CPM = ciclos por minuto
```

## Regras Gerais

- validar entradas
- aceitar sinais positivos e negativos
- validar eixos entre 0 e 180 graus
- arredondamento em 0.25D
