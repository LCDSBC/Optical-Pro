# Regras da IA - OptiCalc Pro

Voce esta desenvolvendo um aplicativo Flutter profissional para Optometria e
Otica.

## Regras obrigatorias

- Utilizar Clean Architecture
- Codigo modular
- Componentes reutilizaveis
- Material Design 3
- Dark Mode Premium
- Responsividade total

## Tecnologias obrigatorias

- Flutter
- Dart
- Firebase
- Provider

## Prioridades do projeto

1. Refracao
2. Conversao LC
3. Prismas
4. Multifocal
5. Terapia Visual
6. Pacientes

## Estrutura obrigatoria

```text
/lib
|-- core
|-- modules
|-- services
|-- providers
|-- widgets
`-- models
```

## Regras de codigo

- Tipagem forte
- Documentacao
- Comentarios quando agregarem contexto tecnico
- Validacoes
- Testes unitarios
- Tratamento de erros

## Design obrigatorio

Visual semelhante a:

- Apple Health
- Tesla App
- Medscape

## Formulas obrigatorias

Consulte `FORMULAS_OPTICAS.md`. Toda formula deve:

- possuir validacao
- aceitar valores negativos
- tratar valores invalidos
- possuir documentacao tecnica
