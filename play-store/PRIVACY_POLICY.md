# Politica de Privacidade — OptiCalc Pro

**Ultima atualizacao:** 5 de junho de 2026

## 1. Introducao

O OptiCalc Pro ("nos", "aplicativo") respeita a privacidade dos usuarios. Esta politica descreve como tratamos informacoes ao utilizar o aplicativo.

## 2. Dados coletados

### Dados inseridos pelo usuario

O aplicativo permite cadastrar pacientes e receitas opticas. Esses dados sao armazenados **localmente no dispositivo** do usuario.

### Dados de autenticacao (opcional)

Quando o Firebase esta configurado, o usuario pode autenticar-se com e-mail. Nesse caso, o Firebase Authentication processa credenciais conforme a politica do Google Firebase.

### Dados tecnicos

O aplicativo pode verificar conectividade de rede (INTERNET, ACCESS_NETWORK_STATE) para funcionalidades online.

## 3. Uso dos dados

Os dados sao utilizados exclusivamente para:

- Realizar calculos opticos solicitados pelo usuario
- Armazenar historico de pacientes no dispositivo
- Sincronizar dados quando Firebase estiver ativo (opcional)

## 4. Compartilhamento

Nao vendemos, alugamos ou compartilhamos dados pessoais com terceiros para fins de marketing.

Dados podem ser processados pelo Google Firebase apenas quando o usuario ativa essa integracao.

## 5. Armazenamento e seguranca

- Dados locais permanecem no dispositivo do usuario
- Recomendamos manter o dispositivo protegido por senha ou biometria
- O usuario pode excluir dados do aplicativo desinstalando-o ou limpando os dados do app

## 6. Direitos do usuario (LGPD)

Conforme a Lei Geral de Protecao de Dados (Lei 13.709/2018), o usuario pode:

- Solicitar informacoes sobre dados tratados
- Solicitar exclusao de dados armazenados em servicos conectados
- Revogar consentimento para uso de servicos online

## 7. Menores de idade

O aplicativo e destinado a profissionais de optometria e otica. Nao coletamos intencionalmente dados de menores de 18 anos.

## 8. Alteracoes

Esta politica pode ser atualizada. A data da ultima revisao sera indicada no topo do documento.

## 9. Contato

Para duvidas sobre privacidade, entre em contato pelo e-mail de suporte informado na listagem do Google Play.
